# tradebot MCP bridge

Lets Claude run backtests, sweep parameters, and draw equity curves against the
local tradebot engine — in any Claude session, no scripts to write.

Registered as a user-scope MCP server:

    claude mcp add tradebot --scope user -- ~/trading/.venv/bin/python ~/trading/mcp/server.py

## Tools

| Tool | What it does |
|---|---|
| `backtest_run` | One backtest → return, max drawdown, Sharpe, win rate, profit factor, trade/signal/rejection counts, equity curve |
| `backtest_sweep` | Same backtest across a range of one parameter, ranked by Sharpe. Finds which stop/target/confidence actually holds up |
| `backtest_chart` | Runs a backtest and renders the equity curve to SVG (drawdown band shaded) |
| `market_quote` | Live quote via the QuantCore Go proxy on :8080 |

Tunable: `source` (synthetic/coinbase/csv), `symbol`, `bars`, `cash`, `seed`,
`risk_profile`, `stop_loss_pct`, `take_profit_pct`, `risk_per_trade_pct`,
`max_position_pct`, `min_confidence`, `fee_pct`, `slippage_pct`.

## Design notes

- **Stdlib only.** The tradebot venv already carries the engine's dependencies;
  an SDK here would be one more thing to keep working. MCP over stdio is just
  JSON-RPC, and the SVG is hand-rolled so charting needs no plotting library.
- **Deterministic by default.** `Brain(use_llm=False)` and a fixed seed, so a
  sweep compares parameters rather than LLM sampling noise.
- **Read-only.** Nothing here can place an order. Every tool runs against the
  paper broker on synthetic or historical candles.

## Caveat that matters

Synthetic candles are generated by the same random walk every run. A strategy
that looks good on them has been fitted to one path, not validated. Vary `seed`
and `source` before believing any result.
